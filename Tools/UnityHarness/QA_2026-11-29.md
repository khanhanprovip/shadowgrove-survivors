# Shadowgrove QA — 2026-11-29

## Changes

- Main-menu Quit asks for confirmation. Cancel/Escape keeps the menu open; Confirm invokes the configured exit callback, or `Application.Quit` when no callback exists. This also fixes the reproduced null callback exception.
- Pause > Save & Main Menu asks before writing/replacing the run checkpoint. Cancel/Escape keeps the round paused. Save failure keeps the player in the paused round and displays a localized failure message.
- Pause > Main Menu warns about unsaved run progress before leaving. Internal checkpoint/scene-transition APIs remain immediate.
- The reusable VI/EN confirmation overlay blocks pointer input, selects Cancel by default, and prevents repeated execution of its action. Resume is blocked while confirmation is open.
- Settings and permanent-upgrade backgrounds now block clicks reaching main-menu controls behind them.
- Launch resolution flags apply initially; subsequent UI display changes take effect. Audio-only settings changes preserve the current window size instead of repeatedly reapplying launch/saved resolution.
- Audio voice replacement respects an incoming cue's lower category limit, and reserves enough lower-priority voices before stopping any.
- Checkpoints omit regenerated cosmetic boss VFX child renderers. Older checkpoints recognize those exact cosmetic renderer records while retaining functional boss phases, hazards, projectiles and other world state. Missing-transform diagnostics now identify the entity and path.

## Test reliability

New suites: `confirmations`, `ui-interactions`, `audio-budget`, `full-smoke-30`, `deep-modes`. The existing `killtarget-burst` suite is exposed through the harness. `level-heal` now covers all three heroes.

Runtime-created UI must complete its Canvas/raycaster registration before pointer probes. The confirmation tests explicitly wait for that pass. The nested test driver disposes remaining enumerators after failure, ensuring `finally` removes its quit interceptor. Original FAIL reports remain in the evidence history.

`full-smoke-30` covers ten stages × three heroes, alternating VI/EN; it checks entry, geometry, terrain, movement and pause, not thirty completed matches. `deep-modes` completes eight normal-stage outcomes using a 3× game clock and runtime-only HP padding; campaign bosses receive a direct test hit after their entrance. It is a functional outcome test, not a balance or manual playthrough.
